# Screenshots

Documentation images for the block's README.

**The account avatar in the Studio header has been replaced with a neutral
placeholder** in `create-impulse.png`, `deployment.png` and `model-testing.png`.
The original screenshots carried a recognisable photograph of a person's face,
which is not something to publish incidentally. `training.png` never included
the header.

If you regenerate any of these, redact the avatar again before committing — it
sits at roughly (2259, 59) with a radius of 38 px at the current 2308 px width.

These images illustrate the Studio workflow; some were captured against other
projects, so the class names in them (`lamp`/`plant`, `no_duck`) do not match
this repository's rock-paper-scissors model.
