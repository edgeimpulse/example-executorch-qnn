# Binary and document provenance

Every non-source file this repository ships has an origin, a license, and an
analysis note. This exists so a license or supply-chain audit has a written
answer for each binary instead of an unexplained blob.

Scope: files that are not plain source text. All project-owned source carries
a `Copyright (c) 2026 EdgeImpulse Inc.` line and the SPDX identifier
`BSD-3-Clause-Clear` in its header; it is not repeated here.

The authoritative statement of what is shipped versus what is fetched at
install time is [NOTICE](../NOTICE).

## Model artifact

| Path | Bytes | SHA-256 (first 16) |
|---|---|---|
| `demo/rps-amazing-hand/models/model.pte` | 2,476,304 | `3c0a837d3e5ada18` |

**Category:** trained machine-learning model, ExecuTorch program.

**Origin:** produced by this repository's learning block
(`blocks/learning-image-classifier/`) from images collected for this project.
Fine-tuned from torchvision's ImageNet-pre-trained MobileNetV2 weights.

**License:** `BSD-3-Clause-Clear`, as a work of this project. The torchvision
weights it was fine-tuned from are distributed by torchvision under
BSD-3-Clause.

**Analysis:** a trained model is a derivative of its training data, so the
provenance and consent position recorded in [dataset.md](dataset.md) govern
this file as well as the images. The images themselves are not published. This
file contains no third-party code and no Qualcomm runtime components; it is an
XNNPACK-delegated CPU program and carries no compiled Hexagon binary. The
NPU-lowered `model_qnn.pte` is **not** shipped in this repository.

## Android preprocessing test fixtures

| Path | Count | Bytes |
|---|---|---|
| `demo/rps-android/core/src/test/resources/golden/*.rgba` | 6 | 2,764,800 |
| `demo/rps-android/core/src/test/resources/golden/*.nchw` | 6 | 1,056,768 |

**Category:** raw test fixtures — uncompressed image buffers and the tensors
derived from them.

**Origin:** generated by
[`demo/rps-android/tools/make_golden.py`](../demo/rps-android/tools/make_golden.py)
in this repository. The `.rgba` files are synthetic input images; the `.nchw`
files are the expected preprocessing output for each, used by
`PreprocessGoldenTest` to prove the Kotlin and Python preprocessing agree.

**License:** `BSD-3-Clause-Clear`, as works of this project.

**Analysis:** these are the only raw image buffers in the repository, so they
warrant an explicit statement. The images are **synthetic** — a procedurally
generated color gradient with a solid circle — and contain no photographic
content, no people, and no camera capture. They are reproducible by re-running
the generator. The file names encode the orientation, ROI, and input size for
each case.
