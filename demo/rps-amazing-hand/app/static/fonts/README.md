# Fonts

Both families are licensed under the **SIL Open Font License, Version 1.1**,
which requires the licence to travel with the font files. The full text for
each is in this directory and must stay alongside the `.woff2` files if they
are copied elsewhere.

| Family | Files | Copyright | Licence |
|---|---|---|---|
| [Atkinson Hyperlegible](https://www.brailleinstitute.org/freefont/) | `atkinson-*.woff2` | Copyright 2020 Braille Institute of America, Inc. | [OFL-Atkinson-Hyperlegible.txt](OFL-Atkinson-Hyperlegible.txt) |
| [Barlow](https://github.com/jpt/barlow) | `barlow-*.woff2` | Copyright 2017 The Barlow Project Authors | [OFL-Barlow.txt](OFL-Barlow.txt) |

The copyright lines above are the ones embedded in the font files themselves;
the licence texts are the per-family `OFL.txt` from
[google/fonts](https://github.com/google/fonts), unmodified.

They are served locally rather than from a CDN so the demo works with no
network — a booth requirement, not a styling choice.

Under the OFL these fonts may be used, modified and redistributed freely, but
not sold on their own, and any modified version must not use the reserved font
names.
